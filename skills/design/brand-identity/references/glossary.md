# Glossary

One meaning each. Use these words everywhere: in chat, files, scripts and the run log. Give the plain gloss the first time the user meets a term.

| Term | Plain gloss |
|---|---|
| brief | The agreed summary of who the brand is for, what it stands for and where it will be used. |
| big idea | The one-line thought every visual decision traces back to. |
| attribute | A word the brand should be felt as (e.g. "precise", "warm"). |
| slider | A 1–5 position between two opposite qualities, such as Playful ↔ Serious. |
| word map | A tree of associations from the brand's words, with the ones that could become images flagged. |
| motif | A word-map idea flagged as drawable. |
| reaction board | A sheet of six lettered tiles the user reacts to ("more of", "not this") instead of naming colours or shapes cold. |
| territory | The visual space the reactions mark out for the routes. |
| route | One distinct idea for the identity, with its own mark and rationale. Replaces "concept", "direction" and "option". |
| mark | The drawn symbol or lettering. Types: **wordmark** (the name set as lettering), **letterform** (one or two letters), **pictorial** (a recognisable thing), **abstract** (a shape with no literal subject). |
| master | The reference drawing of the mark, used at large sizes. |
| small master | A simplified drawing used at 16–32 px when the master breaks down there. |
| lockup | A fixed arrangement of mark and wordmark (horizontal, stacked). |
| logo system | The whole set: master, small master, wordmark, lockups and colourways. "Logo" always means this. |
| gate | The ordered checks a mark must pass before the user sees it. |
| hard fail | A gate result that stops the mark; it must be redrawn. |
| flag | A known weakness the construction log must fix or justify. |
| anchor set | Four to six known-good marks of the same mark type the candidate is compared with. |
| redraw | A new revision that changes what a failed check named. |
| kit | The delivered folder: logo system, colour, type, graphic language, brand sheet and UI design system. |
| token | A named design value (colour role, spacing step, radius, duration) used by the UI system. |
